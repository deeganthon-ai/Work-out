# HomeFit Pro - Workout Only Expanded

Workout-only build with nutrition removed.

Includes:
- Workout, Recovery, Targets, History, Settings tabs
- Smart balanced Push/Pull/Legs generator
- Add / Swap / Remove on each exercise
- Hidden exercise database
- Goal selection
- Muscle recovery scores
- Workout history
- PR tracking
- Volume tracking
- Rest timer
- Equipment toggles with no max weight limits
- Custom exercises
- Backup / restore
- Dumbbell app icon
- Expanded exercise database: 200 exercises
